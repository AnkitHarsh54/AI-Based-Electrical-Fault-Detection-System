AI-Based Electrical Fault Detection System

This project presents a machine learning-based system for detecting electrical faults using MATLAB and Neural Networks.

The system analyzes electrical parameters such as:

Voltage

Current

Temperature

Power Factor

Frequency

and predicts possible faults in electrical systems.

Key Features

Neural network-based fault classification

Data preprocessing and normalization

MATLAB App Designer interface

Real-time fault prediction

Fault description display
